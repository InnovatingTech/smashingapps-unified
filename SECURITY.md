# Security Policy

Security fixes are considered for the latest version on the default branch.

Do not disclose suspected vulnerabilities, API keys, CAPTCHA configuration or user data in a public issue. Use this repository's **Security** tab and **Report a vulnerability** option. Include the affected version or commit, route, impact and safe reproduction steps without secrets.

If private reporting is unavailable, contact [Opace Digital Agency](https://opace.agency/get-in-touch) and identify this repository. Reports are reviewed on a best-effort basis; this policy does not create a support SLA.
